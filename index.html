Windows
התקנה עם קובץ EXE
↓ הורדה ישירה ל־Windows

קובץ התקנה שפורסם ב־GitHub. גרסת Windows החדשה ביותר מהבנייה האחרונה זמינה גם בדף הבנייה (דורשת כניסה ל־GitHub).

  1. הורידו את קובץ ההתקנה למחשב.הקובץ יופיע בדרך כלל בתיקיית ״הורדות״ (Downloads).
  2. פתחו את קובץ Setup.3.0.0.exe.
  3. פעלו לפי אשף ההתקנה ובחרו את תיקיית ההתקנה לפי הצורך.
  4. פתחו את ״מרחב הטיפול״ מתפריט התחל או מקיצור הדרך שנוצר.
אם Windows מציג התראת SmartScreen

בדקו שהקובץ הורד מהקישור הרשמי בעמוד. רק אם אתם סומכים על המקור ואימתתם את הקובץ, ניתן לבחור ״מידע נוסף״ ואז ״הפעל בכל זאת״. אין להתעלם מהתראה על קובץ זדוני.

⌘
Mac
כולל הסבר על אישור פתיחה ב־macOS
↓ קבלת גרסת Mac מ־GitHub ↗

חשוב: זו כרגע הורדה דרך GitHub Actions, לא קישור DMG ישיר. יש להתחבר לחשבון GitHub ולהוריד את mac-build באזור Artifacts. קובצי הבנייה זמינים לזמן מוגבל.

  1. היכנסו ל־GitHub דרך הכפתור שמעל, גללו אל Artifacts ובחרו mac-build.
  2. חלצו את הקובץ שהורדתם אם הגיע כ־ZIP, ואז פתחו את קובץ ה־DMG.
  3. גררו את ״מרחב הטיפול״ לתיקיית Applications (יישומים) וסגרו את חלון ה־DMG.
  4. נסו לפתוח את האפליקציה מתוך תיקיית Applications. ייתכן שתוצג הודעה שאי אפשר לאמת את המפתח.
  5. אם מופיעה הודעת מפתח לא מזוהה: פתחו את ״הגדרות המערכת״ ← ״פרטיות ואבטחה״, גללו לאזור האבטחה ובחרו ״פתח בכל זאת״ (Open Anyway) עבור האפליקציה. אשרו שוב ״פתח״.
  6. בהפעלות הבאות בדרך כלל אפשר לפתוח את האפליקציה כרגיל מתיקיית Applications.
הערה חשובה על אבטחת Mac

גרסת הבנייה אינה מוצגת כאן כאפליקציה שאושרה על ידי Apple. יש לאשר פתיחה רק אם אימתתם שההורדה מגיעה מהפרויקט שלכם ושאתם סומכים על הקובץ. אם המערכת מציגה שהיישום פגום או עלול להזיק למחשב — אל תעקפו את האזהרה; פנו לתמיכה. הנחיות Apple ↗.

שאלות נפוצות

טוב לדעת לפני שמתחילים

האם צריך אינטרנט כדי להשתמש בתוכנה?

השימוש השוטף בתוכנה מתבצע מקומית על המחשב, בלי חיבור לשרת ענן. חיבור לאינטרנט נדרש להורדת קובצי ההתקנה.

איפה נשמר המידע של המטופלים?

המידע נשמר בסביבת המחשב המקומית. חשוב להגן על המחשב באמצעות סיסמה, להקפיד על גיבוי בטוח ולשמור את קובצי הגיבוי במקום מוגן.

למה ב־Mac צריך ללחוץ על ״פתח בכל זאת״?

macOS עשוי לחסום פתיחה ראשונה של יישום שהמפתח שלו לא אומת או שלא עבר את תהליך האישור של Apple. מומלץ להעדיף תוכנות חתומות ומאושרות; אם בחרתם להתקין את גרסת הבנייה הנוכחית, בדקו את מקור הקובץ ופעלו רק לפי ההנחיות למעלה.

צריך חשבון GitHub כדי להוריד?

להורדה הישירה של קובץ Windows שפורסם כ־Release לא נדרש חשבון. כדי להוריד את גרסת ה־Mac הנוכחית מתוך GitHub Actions, יש להתחבר לחשבון GitHub.

האם סרטון ההדרכה כבר זמין?

עדיין לא. יוקלט סרטון הסבר נפרד, ועד אז אפשר להיעזר במדריך ההתקנה שבדף ולפנות אלינו לקבלת עזרה.
